AI Contribution Policy
----------------------

We allow the use of AI tools (such as GitHub Copilot, ChatGPT, etc.) to assist in writing code or documentation for RADIS. To ensure the quality and maintainability of the project, we ask that you follow a few simple guidelines when submitting AI-assisted contributions.


Before submitting a Pull Request with AI-generated content, please ensure that:
1. You fully understand every line of code submitted.
2. All the lines that you generated are genuinely useful and necessary for your feature or fix.

AI tools can sometimes produce incorrect or suboptimal code, so we rely on your expertise to validate the output. By opening a Pull Request, you take responsibility for the code, whether it was written by you or generated by an AI.
Also note that your code will be reviewed if
- your Pull Request passes the CI tests
- your additional features or bug correction are associated with new tests
